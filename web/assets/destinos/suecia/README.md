# Fotografías de Suecia

Sube tus imágenes desde GitHub seleccionando la rama **main** si deseas cambiar producción, o **quality** si deseas probarlas allí. Los archivos de esta carpeta pertenecen a Suecia. Crea subcarpetas como `estocolmo/gamla-stan/` cuando tengas nuevas fotografías. Usa nombres descriptivos sin espacios, por ejemplo `gamla-stan-calle-01.webp`.

**Subir una imagen no la inserta en la página:** después añade su ruta al dato `heroImage` o al campo `image` de una tarjeta en `web/content/destinos/suecia.js`. Para una foto subida a `web/assets/destinos/suecia/estocolmo/gamla-stan/01.webp`, la URL sería `/web/assets/destinos/suecia/estocolmo/gamla-stan/01.webp` mientras el despliegue actual siga sirviendo la raíz del repositorio. No borres ni muevas imágenes utilizadas por otras páginas sin revisar sus referencias.

Esta carpeta prepara la biblioteca de fotos. Las imágenes actuales siguen usando sus URLs originales hasta que se sustituyan conscientemente.
